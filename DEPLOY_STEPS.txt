-- Check all tables exist
SELECT 'bronze_claims' AS table_name, COUNT(*) AS rows
FROM na-dbxtraining.hls_sas_dbx_claims.bronze_claims
UNION ALL
SELECT 'silver_claims_enriched', COUNT(*)
FROM na-dbxtraining.hls_sas_dbx_claims.silver_claims_enriched
UNION ALL
SELECT 'gold_claims', COUNT(*)
FROM na-dbxtraining.hls_sas_dbx_claims.gold_claims
UNION ALL
SELECT 'gold_daily_summary', COUNT(*)
FROM na-dbxtraining.hls_sas_dbx_claims.gold_daily_summary
UNION ALL
SELECT 'gold_weekly_summary', COUNT(*)
FROM na-dbxtraining.hls_sas_dbx_claims.gold_weekly_summary
UNION ALL
SELECT 'gold_affected_batch_analysis', COUNT(*)
FROM na-dbxtraining.hls_sas_dbx_claims.gold_affected_batch_analysis;

-- Expected: All tables with ~15K rows (except summaries which are aggregated)

-- Check affected batch
SELECT COUNT(*) AS affected_claims,
       SUM(claim_amount_usd) AS total_amount
FROM na-dbxtraining.hls_sas_dbx_claims.gold_claims
WHERE is_affected_batch = TRUE;

-- Expected: ~340 affected claims

-- Check for spike alerts
SELECT week, weekly_claims, ratio, status
FROM na-dbxtraining.hls_sas_dbx_claims.gold_weekly_summary
WHERE status = 'ALERT'
ORDER BY week DESC;

-- Expected: ALERT status for weeks with spike

TROUBLESHOOTING
================================================================================

Pipeline fails with "Table not found":
- Verify source tables exist in demo_bravo_insurance_claims schema
- Run data generation SQL from DEPLOY.md Step 1

Pipeline stuck in INITIALIZING:
- Normal for serverless cold start (wait 5 min)
- Check Event Log for errors

Column not found errors:
- Verify schema matches between source and pipeline
- Check SCHEMAS.md for expected schema
