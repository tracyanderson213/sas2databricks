## 📄 What Each Converted File Contains

### **Example: `simple_select.py`**

The converted file will look like:

```python
# Auto-generated by sas2databricks
# Source: simple_select.sas
# Target: SDP (Spark Declarative Pipelines)
# Model: opus-4.8

from pyspark import pipelines as dp
from pyspark.sql import functions as F

@dp.table(name="class_select")
def class_select():
    """
    Original SAS:
    proc sql;
        select Name, Age, Height, Weight
        from sashelp.class
        where Age >= 14
        order by Age desc;
    quit;
    """
    return spark.sql("""
        SELECT Name, Age, Height, Weight
        FROM `na-dbxtraining`.reference_data.class
        WHERE Age >= 14
        ORDER BY Age DESC
    """)
```

**This is your end product** - ready-to-run SDP pipeline code!
